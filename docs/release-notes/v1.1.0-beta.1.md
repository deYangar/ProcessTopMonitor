# ProcessTopMonitor v1.1.0-beta.1 — 显存统计口径修复

**预发布说明**：本版切换了显存数据源（性能计数器 → 内核显存管理器统计），先以 beta 发布观察稳定性。如发现显存数值与任务管理器不一致，欢迎提 issue 附上两侧截图。

## 修复

- **修复部分进程显存显示异常巨大**（可累积到上百 GB，远超物理内存）：根因是 Windows「GPU 进程内存」性能计数器存在已知缺陷（微软官方故障排查文档在案，数值只增不减），任务管理器进程详情页同源同病。本版改用与任务管理器**性能页**相同的内核统计口径（显存管理器记账），逐进程数值与系统级汇总均以真实占用为准
- **修复标题栏显存汇总**：此前汇总走进程加总（受上述缺陷影响），现直接采用系统级适配器真值，与任务管理器性能页 GPU 卡片的显存数字一致
- **修复极老系统备用统计路径**：Windows 8 ~ Windows 10 1607 的备用 GPU 统计查询存在参数传递缺陷（引擎/内存类型拆分失效），本版已修正
- **以管理员运行宿主时**，受保护系统进程（如 dwm 桌面合成）的显存占用现在可以正常显示（普通权限下如实缺席）

## 升级效果对照（实例）

升级前：视频类应用显存显示可达 100+ GB 且持续增长；升级后：同场景显示数百 MB，与任务管理器性能页一致。
